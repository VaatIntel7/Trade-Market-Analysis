# Global Trade Analysis Dashboard

I built this project to better understand how trade flows across different parts of the world and what those patterns reveal about economic relationships between countries. Rather than just presenting numbers on a dashboard, the focus here was on turning raw trade data into insights that are clear, practical, and easy to explore.

This analysis looks at global trade activity across 159 countries, breaking down import trends, regional performance, and the differences between developed and developing economies.

## What This Project Explores

Using trade data from multiple reporting countries, I analyzed:

- Global import distribution across regions  
- Trade activity by income classification  
- Regional market concentration  
- The imbalance between developed and developing economies  
- Patterns that highlight global economic dependence and opportunity  

## Key Insights

A few patterns stood out during the analysis:

- Developing economies account for a large share of global trade activity  
- High-income countries continue to dominate overall trade value  
- Trade distribution is uneven across regions, with clear concentration in major economic hubs  
- Some fast-growing regions show strong participation but lower value contribution  

These findings highlight how trade volume alone doesn’t always reflect economic influence.

## Tools Used

- Power BI — dashboard design and interactive visualizations  
- Python — data cleaning and transformation  
- Excel / CSV — initial exploration and validation
